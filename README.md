BLACKTIDE — a rainy dockyard stealth game. Retrieve 3 cargo manifests and reach the harbour gate unseen.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD move, Shift run (loud), C crouch, Q throw a bottle, E pick up / exit, P pause, R restart, M mute.
